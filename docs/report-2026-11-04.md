## 3. Why stock navigation may fail: from Hiwonder's own docs

Details: `docs/car2-factory-restore.md`. In short:

1. **Chassis type:** must be set with Hiwonder's configuration tool (Save → Apply → Quit, then the beep). On car #2 it was set by hand.
2. **2025 hardware vs software:** the 2025 Ackermann version steers up to 40°, while the software and our sim assume 29–37°. Hiwonder points to "2025 version documentation" that we don't have. A wrong steering limit alone can make TEB report "not feasible".
3. **Calibration:** no IMU or odometry calibration after our motor-direction and trim changes.
4. **Our procedure differed from theirs:**
   - Map: theirs is slow keyboard teleop with a closed loop.
   - Goals: theirs come from RViz.
   - Startup: theirs uses `~/.stop_ros.sh`.
